# Aetherblade: Steel & Steam

A small, offline, browser-playable sword-duel prototype set on a rain-soaked Victorian street. The current build is a responsive 2D Canvas vertical slice—not a Unity project or native Android package.

## Run

Serve this folder with any static HTTP server, then open `index.html` in a modern browser. For example:

```sh
python3 -m http.server 3002
```

## Controls

- **Touch:** choose High/Mid/Low, then Strike. Hold Guard to defend; tap Parry as the opponent's attack lands; Feint cancels your wind-up.
- **Keyboard:** `1` / `2` / `3` select a line, `Space` strikes, `F` holds guard, `Q` parries, `E` feints, and `Escape` pauses.
- Match the incoming line with your selected guard; parries require timing. Manage stamina and land strikes during openings.

## Scope and verification

The prototype includes one AI duel, a procedural street scene, one longsword style, combat HUD, touch/keyboard input, pause, and rematch. It has been checked in Chromium at desktop and phone-sized viewports. No Unity/URP conversion, Android APK, 3D character assets, or on-device Android test is included.
